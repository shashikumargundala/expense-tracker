Sign-in

The first thing Shylock sees, and the only screen while signed out. The brand sits over the aurora with one action, “Continue with Google”, and one calm line on privacy. After he continues, the app finds or creates his Expense Sheet in Drive.

State 1 · Signed out

The only screen reachable while signed out. The brand mark reuses the hero chart rings over the aurora. One gradient “Continue with Google” button, then the privacy line. No nav and no FAB.

State 2 · Signing in

After “Continue with Google”, the button gives way to a progress ring and “Setting up your Expense Sheet…” while the Expense Sheet is found (new phone) or created (first sign-in). Then Home opens with loading placeholders. The privacy line stays.

Compose / M3 notes
  • Layout: a Column with the brand (centered, weight 1f) above the action area. Edge-to-edge, with the action above the gesture bar.
  • Brand mark: a static Canvas reusing the hero chart drawArc code (5 Category segments with 2° gaps, inner sweepGradient orbit). Decorative, so contentDescription = null.
  • Button: Button with a gradient Brush background ending on #DB2777 so the white label passes AA. testTag signin_continue_google. It squashes on press (scale about 0.92) unless Remove animations is on.
  • Signing in: the button is replaced, not disabled, by a CircularProgressIndicator plus the status text. Use liveRegion = Polite so TalkBack reads “Setting up your Expense Sheet…”.
  • No sign-in error or cancelled state is defined in EXPERIENCE.md, so none is drawn here. If the Google sheet is dismissed, the screen returns to State 1.
