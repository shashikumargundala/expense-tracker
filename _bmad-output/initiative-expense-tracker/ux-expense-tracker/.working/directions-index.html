Home page: four design directions

All four are playful and premium, and all are buildable in Material 3 on Jetpack Compose. Each page shows the home screen for Shylock in October 2026 three times: light, dark, and a 320 dp narrow phone at 1.75× font scale. Each one shows the WARNING state (Food at 85%), the EXCEEDED state (Shopping, ₹450 over), one expense waiting to sync, and the Inbox hint with 3 new bank SMS.

  • How they differ. Density runs from Ledger (densest) through Sticker and Orbit to Jelly (airiest). Type weight runs from Ledger (serif, 500) through Orbit (650) to Jelly and Sticker (900). Shape runs from square (Ledger) through squircle (Jelly) and outlined boxes (Sticker) to circles (Orbit). Motion runs from inky (Ledger) through orbiting (Orbit) and springy (Jelly) to snappy (Sticker).
  • Every file is self-contained: inline CSS, system fonts, inline SVG icons, no JS and no network. Hex tokens for light and dark are documented in each file's <style> comments and shown as swatches.
