After the swipe, an M3 alert dialog over a scrim asks before deleting. Cancel returns the row. Delete is the filled red action.

Compose / M3 notes
  • Rows: LazyColumn with stickyHeader per day (“Today”, “Yesterday”, then “EEE, d MMM”). Each header carries the day total.
  • Swipe: SwipeToDismissBox with EndToStart only. The background is a red Surface with the trash icon and “Delete” label. The dismiss threshold opens the AlertDialog instead of deleting at once.
  • Waiting to sync: a small tonal chip on rows where synced = false. It clears when the Sheets write succeeds.
  • Filters: SingleChoiceSegmentedButtonRow for the period, and a horizontally scrolling row of FilterChip for Categories.
